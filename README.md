# Mockora — AI Mock Interview Assistant

An intelligent, interactive humanoid AI mock interview coach built for college students and job seekers. Practice real-time technical interviews tailored to your resume, receive immediate dynamic evaluations, and get actionable performance reports with email delivery.

## Key Features

- **Resume Parsing & Tailored Questions**: Extracts skills, projects, and experiences to generate dynamic, contextual interview questions.
- **Interactive Humanoid Robot Avatar**: Visual feedback states (idle, listening, thinking, speaking) responsive to interview progression.
- **AI Scoring Engine**: Evaluates answers across 6 core criteria (Technical Accuracy, Relevance, Communication, Structure, Problem Solving, and Examples).
- **Comprehensive Assessment Reports**: Strengths, areas to improve, recommended study topics, and automated email reports.

## Tech Stack

- **Frontend**: React 19, Vite, Lucide Icons, Canvas-Confetti, Vanilla Cyber-styled CSS
- **Backend**: FastAPI (Python), SQLite / Supabase PostgreSQL, Google Gemini AI API, SMTP Email Service
